# 给网页 AI 的直接工具 SOP

先阅读 [ChatGPT](../docs/chatgpt.md)或 [Claude](../docs/claude.md)的账号条件。本提示词约束操作过程，不授予平台未开放的能力，也不能替代执行器的权限校验。

下面的内容可以复制到已经连接自己 MCPX 的网页对话。把演示任务换成真实项目之前，先明确目录、目标和允许动作。

```text
目标：通过当前已授权的 MCP 连接器操作我自己的 Windows。默认使用直接文件或命令工具，不启动本机 Codex 或其他模型任务，除非我明确要求模型委派。

本次工作区：C:/MCPX/demo。
本次任务：读取 marker.txt，说明当前内容；提出一处明确修改，再按我本次已授权的目标完成修改并核对实际结果。

开始前：
1. 检查当前连接器实际暴露的工具和输入 schema。若有操作手册，先读手册。
2. 区分原生 MCPX 和扩展网关，只按当前入口的真实契约调用。原生可能使用 remote_session_id；windows_* 扩展使用 session_id，二者不能混用。
3. 为当前工作建立或取得自己的会话，保存返回的工作区和会话标识。后续工具要求会话参数时每次都带上，不使用旧的免会话写入口。

执行时：
4. 修改文件前读取最新内容和版本/哈希。写入携带工具要求的预期版本，冲突时重新读取后合并，不能强制覆盖其他会话的修改。
5. 命令使用准确的可执行文件和参数。没有必要时不额外增加 Shell，不读取凭据、浏览器资料或无关账号数据。
6. 长任务一旦接纳，保存任务 ID 与输出游标。断线后先查询原任务，不能为了确认是否成功而重复提交。
7. 不同任务共用文件时检查冲突；需要浏览器时使用专用标签页。需要同一 Windows 前台的鼠标键盘操作时排队，不争抢窗口。
8. 若缺少工具、权限或认证，说明具体缺项。不能把网页中的“已完成”当作本地执行证据，也不要把失败猜成成功。

完成时：
9. 回读修改后的文件，报告实际修改、检查方式和结果；命令报告退出状态及必要输出。未经验证的项目单列为未验证。
10. 在需要扩展目录、公开发布、部署或其他超出本次任务范围的动作前，先说明具体对象和动作，并按已有授权范围处理。

本次授权限于上述演示任务。不要新建或切换模型路线，不改变系统安全配置，不公开密钥或原始截图。
```

若使用作者自用的增强网关，且真实工具清单包含 `windows_get_handbook`、`windows_open_session`、`windows_read_file`、`windows_write_file`、`windows_exec` 和状态查询工具，可按手册执行；工具没有暴露时不能假定它们存在。模型委派入口与直接工具入口分开，启动本机模型会涉及该路线的用量。
