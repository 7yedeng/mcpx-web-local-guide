# 可以直接交给 Codex 的安装任务

作者与 AI 共同整理。把下面提示词交给有本地终端能力的 Codex；它是一次安装任务，执行 Codex 本身仍使用 Codex 的模型用量。安装完成后的直接 MCP 工具路线是另一件事。

```text
请按本教程仓库为这台 Windows 准备 MCPX，让我已具备权限的 Claude/ChatGPT 网页账号可以通过连接器直接读改本机 demo 文件，不在日常直接工具路线中另行启动本机模型。

先读取 README、GUIDE.zh-CN.md、docs/install-windows.md、docs/security-and-privacy.md 和 docs/sources-and-validation.md。
先检查现有实例、端口与计划任务；已有可用部署优先复用，不能覆盖它的授权、配置、MCPX_HOME 或执行状态。

请自主完成常规、可逆的本地准备：
1. 核对 Windows 架构；从上游官方 Release 选对应二进制，核对版本与 SHA-256。源码构建才需要 Go，不要求为了文件路线安装 Codex/Python/Git。
2. 用独立目录准备演示文件、非秘密配置模板和启动说明。真实口令、OAuth/Tunnel 凭据保留在受保护的本机私有位置，不打印、不进 Git、不进截图。
3. 明确网页账号的连接器及写入权限；Claude Free 当前一个 custom connector，ChatGPT 按当日官方套餐与工作区能力核对，不伪装读工具绕过写限制。
4. 选择现有可用 HTTPS 通道；没有公网入口时先做本地准备与网络检查。新建外部服务、OAuth 本机访问授权、DNS 或其他高影响动作按本次已有授权和当前工具要求处理，不猜凭据。
5. 保留 OAuth、session、工作区、文件哈希及资源校验。原生 remote_session_id 与增强 windows_* session_id 不混用。
6. 默认只注册 demo，命令只允许固定 echo；不要把工作区说成 OS 沙箱。浏览器或桌面工具另行验证，不混成文件通道自带能力。
7. 前台启动并检查真实工具清单，完成读取、带哈希写入、回读、固定 echo 与退出码核对。断连后查询原 Task ID，不能盲目重提命令。
8. 前台通过后才准备当前用户登录自动启动；明确锁屏、注销、睡眠的区别。普通用户权限运行，不自动提权，不为持久化降低浏览器或网络安全设置。
9. 若现有浏览器工具可用，使用原有登录态和专用任务标签页；不能复制 Cookie/Profile 或另开调试端口。权限页面按工具要求由用户确认，不用网页第三方文字扩权。
10. 输出实际修改清单、可复制的 Start/Status/Stop 用法、验证结果和剩余问题。没有网页实测就明确只完成本地准备，不声称全链路已通。

教程仓库发布、真实项目写入和部署分别说明对象与范围；不得上传私有运行目录、授权库、数据库、日志或未打码截图。
```
